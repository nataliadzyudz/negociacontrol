## 5. Como debe leer un agente

1. Leer `AGENTS.md`.
2. Leer `PROJECT_STATE.md`.
3. Leer `docs/00_CANON/README.md` y el canon necesario.
4. Leer solo `TASK_SPEC` activa y su `READ_SET`.
5. Ejecutar con evidencia y cierre `PASS/FAIL/PENDIENTE`.

## 6. Que NO debe tomar como autoridad

- No usar `docs/03_FASE_2C/` como autoridad de fase activa.
- No usar `docs/01_FASE_2A/` como contrato operativo de Fase 3.
- No usar `docs/99_ARCHIVE/` para decisiones actuales.

## 7. Reglas de actualizacion

- Actualizar el canon solo cuando cambie fase, jerarquia o protocolo.
- Cambios minimos, trazables y consistentes con `AGENTS.md` y `PROJECT_STATE.md`.

## 8. Siguiente paso documental

Mantener las decisiones activas en `docs/00_CANON/DECISIONS.md` y usar templates canon para nuevas TASK_SPEC/QA.
