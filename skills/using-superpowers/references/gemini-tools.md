# Gemini Tools Reference

## Browser Subagent
Use for:
- Web research (documentation, examples).
- UI/UX verification.
- Testing local files.

## Terminal Commands
Use for:
- Environment setup (`npm`, `npx`).
- Testing (Unit tests, linting).
- File system management.

## File Editing
- `multi_replace_file_content`: Best for non-contiguous changes.
- `replace_file_content`: Best for single blocks.
- `write_to_file`: Best for new files.

## Research
- `grep_search`: Fast pattern finding.
- `search_web`: General knowledge gathering.
